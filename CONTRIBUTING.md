# Contributing

1. Open an issue describing the bug or feature.
2. Fork the repository and create a branch: `feat/short-description` or `fix/short-description`.
3. Make focused changes.
4. Run backend tests: `cd src/backend && pytest`.
5. Run frontend checks: `cd src/frontend && npm run build`.
6. Open a pull request and describe the changes and tests.

Do not commit downloaded GTFS archives, credentials, private data, or generated build output.
